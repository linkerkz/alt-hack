# 001 — Карта сети станций

Статус: done

## Цель

Входной экран диспетчерской системы: карта сети железнодорожных станций, на
которой сразу видно, где проблемы, и откуда можно перейти на пульт станции.

## Направление

- Фича `features/network-map`: моковые станции и участки, сводка по сети,
  карта (Leaflet, как в promtech-hack), список станций, превью выбранной станции.
- Выбранная станция хранится в URL (`?station=`).
- Роут `/stations/[stationId]` — заглушка пульта станции, чтобы клик вёл дальше.
- Тёмная «диспетчерская» тема, состояния Норма / Внимание / Критично по порогам индекса.

## Вне рамок

Пульт станции, realtime-поток, база данных, расчёт индекса по формуле.

## Критерии приёмки

- [x] Карта показывает станции и участки, цвет — по состоянию
- [x] Сводка по сети: средний индекс, число станций по состояниям, сбои
- [x] Клик по станции на карте или в списке открывает превью
- [x] Из превью есть переход на пульт станции
- [x] lint, typecheck, build — зелёные

## Верификация

- Сборка: ok (lint, typecheck, build)
- Миграции/RLS: не затронуто — данные моковые
- Критерии: все отмечены
- Проверено где: localhost (headless Chromium: карта → клик по станции → пульт)
- Примечание: тайлы CARTO теперь требуют API-ключ — подложка Esri World Dark Gray
