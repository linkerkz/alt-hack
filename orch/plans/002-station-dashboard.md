# 002 — Dashboard станции (оперативный отчёт)

Статус: done

## Цель

Аналитический экран-отчёт по одной станции для диспетчера: состояние,
эффективность, выполнение плана, операции во времени, проблемы — считывается
за несколько секунд. Не схема станции (её ведёт другой участник) и не Jira.

## Направление

- Новый роут `app/dashboard/[stationId]/page.tsx`, не трогаем заглушку
  `/stations/[stationId]`.
- Новая фича `features/station-console` (термин «Пульт станции» уже в
  словаре `docs/core.md`).
- Переиспользуем индекс эффективности и его пороги/цвета/статусы — выносим их
  в `lib/status.ts` (были в `features/network-map/status.ts`), так как теперь
  нужны двум фичам, а фичи не импортируют друг друга напрямую. `IndexRing`
  переносится в `components/ui/` по той же причине.
- `station-console` не импортирует типы `network-map` — принимает данные
  станции через собственный структурный тип `StationSnapshot` (форма данных
  на границе фичи), с которым реальный `Station` совместим без приведения
  типов. Склейка происходит в `app/dashboard/[stationId]/page.tsx`.
- Данные, которых нет в модели (операции/Gantt, выполнение плана,
  статистика смены, история индекса, часть «требует внимания») — мок в
  `features/station-console/mock.ts`, детерминированно выводится из реальных
  полей станции.

## Вне рамок

Схема станции, drag-and-drop задач, бэкенд задач/ролей, расчёт индекса по
формуле, realtime, база данных.
