# 007 — Живая карта сети и запрос на согласование ДНЦ

Статус: review

## Цель

Карта сети показывала только моки: состояния сбоев и согласования ДНЦ
жили лишь в макете. Нужно, чтобы карта читала ход инцидентов из базы и
обновлялась сама, а ДНЦ отвечал на запрос ДСЦС («вариант Б — удержать
поезд у соседа») прямо с карты: согласовать или отклонить с комментарием.

## Направление

- Карта перечитывает базу раз в 3 с, как пульт; открытые инциденты станций
  зоны из базы попадают в список сбоев станции.
- Запрос на согласование — карточка поверх карты по макету alt-design v5:
  поезд, удержание, затронутые поезда «с удержанием / не менять», индекс
  станции сейчас / без изменений / с удержанием, комментарий, кнопки.
  Состояния: ждёт ответа, отклонено (можно вернуть на рассмотрение, пока
  ДСЦС не выбрал другой вариант), согласовано.
- Ответ ДНЦ — команда пульта в базу через отдельный Server Action:
  роль ДНЦ и станция его круга (круг станции — в `stations`), шаг проверяет
  сама команда. Ответ пишется в хронологию станции.
- Отказ возвращает ДСЦС к выбору варианта: на пульте видно, что ДНЦ отклонил
  и с каким комментарием, по умолчанию предложен вариант А.
- Станция с запросом выделена на карте и в списке; в сводке зоны — число
  запросов.

## Вне рамок

Показатели и поезда карты из базы (остаются моками), уведомления,
несколько одновременных запросов от одной станции, история запросов.

## Критерии приёмки

- [ ] ДСЦС принял вариант Б — у ДНЦ на карте без перезагрузки появилась карточка запроса
- [ ] «Согласовать» (с комментарием или без) — инцидент решён, у ДСП задачи, в хронологии ответ ДНЦ
- [ ] «Отклонить» — у ДСЦС «ДНЦ отклонил», предложен вариант А; ДНЦ может вернуть запрос на рассмотрение
- [ ] Чужой круг и не ДНЦ ответить не могут (проверка в Server Action)
- [ ] Инцидент из базы виден в карточке станции на карте
- [x] lint, typecheck, build — зелёные

## Верификация

- Сборка: ok (lint, typecheck, build)
- Миграции/RLS: миграция `dnc_approval` — добавочные колонки инцидента
  (`dnc_rejected_at`, `dnc_comment`) и круг станции (`stations.dispatch_area_id`);
  новых таблиц нет. Применена в проект `alt-hack`; у `almaty-1` круг `almaty`
- Критерии: вид трёх состояний карточки проверен на превью в headless
  Chromium; путь ДСЦС → ДНЦ → ДСП на базе не пройден (в окружении нет ключей
  Supabase) — пройти на localhost после миграции
- Проверено где: локальная сборка, превью карточки
