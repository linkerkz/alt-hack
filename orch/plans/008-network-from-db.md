# 008 — Сеть из базы вместо моков карты

Статус: review

## Цель

Карта сети читала станции, участки, поезда и сбои из моков
(`features/network-map/mock*.ts`). Нужно перенести их в Supabase и читать
оттуда, чтобы карта, пульт и dashboard опирались на одну модель сети.

## Направление

- Миграция `network_model`: круги ДНЦ, атрибуты станций (код, тип,
  координаты, показатели), участки, остановки поездов. Время остановок —
  минуты от текущего момента, как было в моках: демо-сеть «живёт сейчас».
- Сид `seed-network.sql` сгенерирован из бывших моков; повторный запуск
  безопасен. Сбои других станций — в `incidents`; сбои демо-станции
  `almaty-1` ведёт пульт, в сид не попадают.
- Фича `network-map` читает сеть одним кэшированным запросом на страницу.

## Вне рамок

Сценарий пульта (`station-console/mock.ts` — что показывать на каждом шаге),
расчёт показателей dashboard (по-прежнему выводится из полей станции), живое
время поездов.

- [ ] Карта ДНЦ на localhost совпадает с прежней (станции, поезда, сбои)
