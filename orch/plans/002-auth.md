# 002 — Авторизация и роли

Статус: review

## Цель

Вход в систему через Supabase Auth и доступ к экранам по роли КТЖ: ДСП видит
пульт своей станции, ДНЦ — карту и станции своего диспетчерского круга, ДС —
свою станцию. Для жюри — быстрый вход под каждой ролью.

## Направление

- Supabase Auth (email + пароль), регистрации нет — пользователей заводит сид.
- Таблица `profiles`: роль, станция, диспетчерский круг; RLS — каждый читает
  только свой профиль. Миграция и сид лежат в `supabase/`, применяются вручную
  через SQL Editor (CLI не подключён).
- `proxy.ts` обновляет сессию и уводит неавторизованных на `/login`.
- Права по роли проверяют страницы; правила доступа — в одном месте фичи `auth`.
- Роли из развития (ДСЦ, составитель, машинист) есть в перечне ролей, но
  экранов у них пока нет.

## Вне рамок

Отчёты ДС, согласование ДНЦ в карточке инцидента, маневровые задачи,
подсветка диспетчерского круга на карте, управление пользователями.

## Критерии приёмки

- [x] Без входа любой экран уводит на `/login`
- [x] Вход паролем и кнопками демо-ролей; неверный пароль — понятная ошибка
- [x] После входа роль попадает на свой стартовый экран
- [x] ДСП/ДСЦС/ДС открывают пульт только своей станции, ДНЦ — станций своего круга
- [x] В шапке видно, кто вошёл, и есть выход
- [x] lint, typecheck, build — зелёные

## Верификация

- Сборка: ok (lint, typecheck, build)
- Миграции/RLS: применены через SQL Editor; RLS на `profiles` включён.
  Типы не перегенерированы — Supabase CLI не подключён, строка профиля
  проверяется вручную
- Критерии: все отмечены
- Проверено где: localhost (headless Chromium: вход под ДСП, ДСЦС, ДНЦ, ДС →
  стартовый экран, чужой пульт уводит домой, превью чужой станции без
  кнопки пульта, выход → /login)
- Статус `review`: ветка ещё не влита в main
