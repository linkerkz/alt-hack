# 003 — Карта зоны ответственности и потоки поездов

Статус: review

## Цель

Карта показывает не всю сеть, а зону ответственности пользователя: ДНЦ — свой
диспетчерский круг, ДСП/ДСЦС/ДС — свою станцию и соседей. На станциях и
участках видно, сколько поездов прибывает, отправляется и идёт проездом.

## Направление

- Моковые поезда с маршрутом и расчётным временем по станциям; все счётчики
  считаются из поездов, а не задаются руками. Горизонт — ближайшие 3 часа.
- Станции зоны — крупные кнопки со счётчиками ↓ прибывают / ↑ отправляются /
  ⇢ проездом. Соседи за границей зоны — бледные, без деталей.
- На участке — число поездов в каждую сторону, стрелки вдоль линии.
- Клик по станции — режим «моя станция»: её участки подсвечены, в карточке —
  направления «к нам / от нас» и ближайшие поезда. У ДСП он включён сразу.
- Карта приближена к зоне и не уезжает от неё; остальная сеть скрыта.
- Зону задаёт роль пользователя (фича `auth`), карта получает её параметром.

## Вне рамок

Анимация поездов, переключатель горизонта, данные из базы.

## Критерии приёмки

- [x] ДНЦ видит только станции своего круга и бледных соседей
- [x] ДСП/ДСЦС/ДС видят свою станцию и соседей, своя станция выбрана сразу
- [x] На станциях зоны — счётчики прибывают / отправляются / проездом
- [x] На участках — число поездов в каждую сторону
- [x] Карточка станции: направления «к нам / от нас» и ближайшие поезда
- [x] lint, typecheck, build — зелёные

## Верификация

- Сборка: ok (lint, typecheck, build)
- Миграции/RLS: не затронуто — поезда моковые (`mock-trains.ts`, сгенерирован
  по сети: маршруты по кратчайшему пути, время по расстоянию)
- Критерии: все отмечены
- Проверено где: localhost (headless Chromium: ДНЦ — Алматинский круг и
  бледные соседи, клик по Алматы-1 → направления и поезда; ДСП — своя станция
  выбрана сразу). «К нам» по направлениям = ↓ + ⇢, «от нас» = ↑ + ⇢
- Единица счёта — движение поезда по участку A → B (в пути или выйдет на
  участок за 3 ч). Из одних движений собраны стрелка на карте, «к нам / от нас»
  у соседа и строки в карточке — сверено скриптом по всем станциям круга:
  стрелка = число строк, Σ «к нам» = ↓ + ⇢, Σ «от нас» = ↑ + проездом
