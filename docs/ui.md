# UI: тема и компоненты

Дизайн — тема «Диспетчерская»: холодный светлый фон, белые карточки с тонкой
рамкой, тёмная шапка-рамка приложения и один шрифт — IBM Plex Sans (технический
гротеск с кириллицей, цифры читаются и в мелких подписях). Жирного нет
(максимум semibold).

Цвета разведены по смыслу и не пересекаются:

- **синий акцент** — только действие и выбор: главная кнопка, текущий раздел,
  выбранный вариант, ссылки;
- **зелёный / янтарный / красный** — только состояние (Норма / Внимание /
  Критично), никогда не действие.

Единственная заливка акцентом — главное действие (`Button` `primary`):
решение, которое ждут от пользователя, видно с первого взгляда. Одно такое
действие на карточку.

## Токены (`app/globals.css`, `@theme`)

| Класс Tailwind                     | Что это                                           |
| ---------------------------------- | ------------------------------------------------- |
| `bg-paper` / `bg-card`             | фон страницы / белая поверхность карточки, поля   |
| `bg-surface`                       | подложка карты, приглушённые зоны                 |
| `bg-chrome`                        | тёмная шапка; внутри неё токены текста и линий переопределены светлыми |
| `text-ink` / `text-muted`          | основной / второстепенный текст                   |
| `border-line`                      | тонкая разделительная линия                       |
| `accent`, `accent-100…900`         | синий акцент действия; текст акцентом — `text-accent-700` |
| `neutral-100…900`                  | холодная серая шкала                              |
| `normal` / `warning` / `critical`  | цвета состояний                                   |
| `font-heading` / `font-sans`       | оба — IBM Plex Sans; `font-heading` — заголовки и крупные числа (с `font-semibold`) |
| `shadow-sm/md/lg`                  | тени — едва заметные                              |

Состояние всегда показываем цветом **и** значком: ● Норма, ▲ Внимание,
■ Критично (`components/ui/tone.ts`); у плашки — ещё лёгкая подложка своего
цвета (`TONE_TINT_CLASS`). Для SVG и Leaflet, где нужен цвет, а не
класс, — `TONE_COLOR`.

## Компоненты (`components/ui/`)

| Компонент      | Когда                                                        |
| -------------- | ------------------------------------------------------------ |
| `Button`       | действие; `primary` — заливка акцентом, только главное действие; `secondary` — обводка, `ghost` — текст; размеры `md/sm/icon` |
| `ButtonLink`   | переход, который выглядит как кнопка                         |
| `Card`         | рамка-поверхность; `emphasis="accent"` — главная карточка, `critical` — карточка сбоя, `elevation` |
| `Kicker`       | надзаголовок капителью над заголовком или списком; `tone` — приглушённый, акцент или состояние |
| `Heading`      | заголовок уровня 1–3 с пояснением `note`                     |
| `IndexValue`   | крупное число в цвете состояния + `StatusBadge` + подпись    |
| `StatusBadge`  | плашка состояния «● Норма»                                   |
| `StatusGlyph`  | только значок состояния — в строках и подписях               |
| `Metric`       | показатель: подпись + крупное число (внутри `<dl>`)          |
| `Meter`        | тонкая полоса долей: заполнение или разбивка по состояниям   |
| `LegendItem`   | строка легенды: образец знака + пояснение (внутри `<ul>`)    |
| `Tag`          | небольшая метка: `neutral`, `accent`, `outline`              |
| `Field`        | поле формы с подписью                                        |
| `Table`        | таблица данных: шапка капителью, строки тонкими линиями      |
| `Disclosure`   | раскрывающийся раздел подробностей: заголовок капителью, `open` — раскрыт сразу |
| `AppHeader`, `LiveClock` | шапка: только открытые роли разделы и реальные часы — других часов на экранах нет |
| `QrCode`       | QR-код ссылки (SVG), размер — через `className`              |
| `DeviceButton` | кнопка экрана устройства (тёмная тема прошивки), `tone="alert"` |
| `LiveRefresh`  | невидимый: перечитывает серверные данные раз в 3 с, пока вкладка видна. Ссылки на таком экране — с `prefetch={false}`, иначе каждое обновление заново предзагружает их все |

## Экраны устройств (`app/(device)`)

Камера и пейджер — исключение из основной темы: это софт полевого устройства, он
выглядит как прошивка. Тёмный экран и моноширинный шрифт (JetBrains Mono,
`font-mono`), токены `device`, `device-panel`, `device-line`, `device-ink`,
`device-dim`, `device-ok`, `device-warn`, `device-alert`. Состояние — тоже
цветом и значком (● ▲ ■). Кнопка — `DeviceButton` (`tone="alert"` — главное
действие). Ссылок из приложения на эти экраны нет.

Новый экран собираем из этих компонентов; не хватает — добавляем сюда новый,
а не пишем разовые стили в фиче.

## Чего не делаем

- Неработающих пунктов меню, кнопок и статусов «для вида» нет: появится
  экран — появится и ссылка на него.
- Подписи, которые повторяют соседний элемент (легенду, заголовок, схему),
  не дублируем — их убирают при первом же наложении.
