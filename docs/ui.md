# UI: тема и компоненты

Дизайн — система «Classical» из Claude Design: светлая бумага, серифные
шрифты, тонкие линии, один золотой акцент. Цвет — обводкой и линиями, а не
заливкой: кнопки и карточки без фона, жирного нет (максимум semibold).

## Токены (`app/globals.css`, `@theme`)

| Класс Tailwind                     | Что это                                           |
| ---------------------------------- | ------------------------------------------------- |
| `bg-paper` / `bg-surface`          | фон страницы / подложка карты, приглушённые зоны  |
| `text-ink` / `text-muted`          | основной / второстепенный текст                   |
| `border-line`                      | тонкая разделительная линия                       |
| `accent`, `accent-100…900`         | акцент; текст акцентом — `text-accent-700`        |
| `neutral-100…900`                  | тёплая серая шкала                                |
| `normal` / `warning` / `critical`  | цвета состояний                                   |
| `font-heading` / `font-sans`       | Cormorant Garamond (заголовки, числа) / Lora      |
| `shadow-sm/md/lg`                  | тени — едва заметные                              |

Состояние всегда показываем цветом **и** значком: ● Норма, ▲ Внимание,
■ Критично (`components/ui/tone.ts`). Для SVG и Leaflet, где нужен цвет, а не
класс, — `TONE_COLOR`.

## Компоненты (`components/ui/`)

| Компонент      | Когда                                                        |
| -------------- | ------------------------------------------------------------ |
| `Button`       | действие; `primary` — обводка акцентом, `secondary`, `ghost`; размеры `md/sm/icon` |
| `ButtonLink`   | переход, который выглядит как кнопка                         |
| `Card`         | рамка-поверхность; `emphasis="accent"` — главная карточка, `critical` — карточка сбоя, `elevation` |
| `Kicker`       | надзаголовок капителью над заголовком или списком            |
| `Heading`      | серифный заголовок уровня 1–3 с пояснением `note`            |
| `IndexValue`   | крупное число в цвете состояния + `StatusBadge` + подпись    |
| `StatusBadge`  | плашка состояния «● Норма»                                   |
| `StatusGlyph`  | только значок состояния — в строках и подписях               |
| `Metric`       | показатель: подпись + серифное число (внутри `<dl>`)         |
| `Meter`        | тонкая полоса долей: заполнение или разбивка по состояниям   |
| `LegendItem`   | строка легенды: образец знака + пояснение (внутри `<ul>`)    |
| `Tag`          | небольшая метка: `neutral`, `accent`, `outline`              |
| `Field`        | поле формы с подписью                                        |
| `Table`        | таблица данных: шапка капителью, строки тонкими линиями      |
| `AppHeader`, `LiveClock` | шапка приложения и часы                            |
| `QrCode`       | QR-код ссылки (SVG), размер — через `className`              |
| `LiveRefresh`  | невидимый: перечитывает серверные данные раз в 3 с, пока вкладка видна |

Новый экран собираем из этих компонентов; не хватает — добавляем сюда новый,
а не пишем разовые стили в фиче.
